# Getting Started

## Requirements

- Arcadyan AW1000 device
- Stable power source
- Ethernet or Wi-Fi access to the device
- A browser for the web UI

## First Boot Checklist

1. Power on the device and wait for the system to boot fully.
2. Connect a client via Ethernet or Wi-Fi.
3. Open the web UI in a browser: `http://192.168.1.1`.
4. Set a strong admin password on first login.
5. Update Wi-Fi SSIDs and passwords.

## Default Access

- Admin username: `root`
- Admin password: not set on first boot
- Default LAN IP: `192.168.1.1`
- Default SSID (2.4GHz): `NoobWRT 2GHz`
- Default SSID (5GHz): `NoobWRT 5GHz`
- Default Wi-Fi password: `123456789`

## Safety Notes

- Always keep stable power while flashing or upgrading.
- Back up your configuration before upgrades.
- If you are unsure, use the recovery methods described in the `Recovery` section.
