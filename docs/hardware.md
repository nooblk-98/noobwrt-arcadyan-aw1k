# Hardware

## LED Indicators

- Power light: device is powered on and ready
- 5G indicator: 5G mobile connection status
- Internet status: active internet connection
- Signal strength: cellular signal quality level
- New SMS: unread SMS messages on the SIM card

## Default Settings

Default Wi-Fi names, password, admin login and LAN IP are listed in [Getting Started](getting-started.md#default-access).

## Phone Port

The RJ11 phone port works with the NoobWRT `rj11` images. See [Phone (RJ11)](phone.md).
