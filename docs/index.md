# NoobWRT for Arcadyan AW1000

NoobWRT is a performance-tuned OpenWrt firmware build for the Arcadyan AW1000. It focuses on speed, stability, security, and a curated app stack with sensible defaults.

## Announcement

!!! warning "Lite Build Discontinued"
	Arcadyan-AW1000-Lite is no longer continued in current builds.

	If you need the Lite version, use the last old release:
	[v2026-02-12-15-17-16](https://github.com/nooblk-98/noobwrt-arcadyan-aw1k/releases/tag/v2026-02-12-15-17-16)

## Scope

This documentation covers the AW1000-specific build, supported firmware images, installation and recovery workflows, and package ecosystem. For general OpenWrt usage, refer to the OpenWrt documentation.
